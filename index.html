FacilityOps AI

github.com/wasif1024/facilityops →

Enterprise agentic AI on Microsoft Foundry for facility maintenance intake, with deterministic safety controls, PII protection and human-in-the-loop workflows.

Tenants report maintenance problems by text, photo, voice note or scanned document, in several languages. Some are emergencies (gas, fire, flooding) and some contain personal data or hidden prompt injections. An AI that misroutes an emergency or leaks data is worse than no AI at all.

  • Triage every request quickly and accurately, in English, Spanish and French.
  • Never let AI delay or decide an emergency.
  • Keep personal data away from models and logs, and keep people in charge of risky or expensive actions.
  • Prove quality with measurable gates, not demos.
  • Built a multimodal intake on Microsoft Foundry and Microsoft Agent Framework using Azure OpenAI, AI Vision, Speech, Document Intelligence and Translator.
  • Designed a deterministic pipeline with a single classifier agent and an emergency bypass before any AI.
  • Escalated incidents go to a Magentic multi-agent team (manager plus six specialists with read-only tools and a Foundry IQ knowledge base) that proposes cited plans for facility-manager approval before the application acts.
  • Added guardrails (Content Safety, Prompt Shields against direct and in-document injection), PII redaction before any model or log, Entra ID / External ID with deny-by-default RBAC, and append-only audit trails.
  • Defined the Azure deployment in Bicep (Container Apps, Key Vault, PostgreSQL, Service Bus, monitoring) with managed identity and no API keys.

04 · Approach

How I build AI systems

Deterministic first, AI second

Safety-critical paths run in plain code before any model is called. In FacilityOps, emergencies bypass the AI entirely, and the classifier only suggests; code decides the route.

Agents propose, people approve

Agents get read-only tools and fixed budgets. They produce cited plans; a person approves, revises or rejects them, and only then does the application act.

Measure before you ship

Golden sets, holdout sets, fairness and injection tests run as quality gates in CI, so a regression blocks the merge instead of reaching users.

Secure and private by default

PII is redacted before any model, log or trace. Access is deny-by-default with Entra ID, services use managed identity with no API keys, and every decision is audited.
